# Optilux

A lean Minecraft shader pack and a benchmark suite for measuring it.

Status: design phase. Nothing to download yet.

- Target: Minecraft 26.3 with Iris and Sodium (Fabric).
- License: MIT (planned).

Optilux is inspired by Complementary Shaders by EminGT. It is a full rewrite and contains no Complementary code.
