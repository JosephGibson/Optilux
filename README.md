# Optilux

A lean Minecraft shader pack and a benchmark suite for measuring it.

Status: in development. The benchmark harness runs in the repository; the release zip still holds a placeholder pack with no programs, and the first real pack arrives with M3.

- Target: Minecraft 26.3 with Iris and Sodium (Fabric).
- License: MIT (see LICENSE).

Optilux is inspired by Complementary Shaders by EminGT. It is a full rewrite and contains no Complementary code.

Changes: each release's notes on its GitHub release page, and CHANGELOG.md in the repository.
