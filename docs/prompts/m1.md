## Rules
- Format, parsed by `optilux status`: one `## 0.MM.PP <title>` heading per phase, each followed by exactly one fenced block holding the prompt; `## Resume` last, with one fenced block (prompts/m0.md#rules).
- Prompts are never rewritten per session (workflow.md#running-a-milestone); a wrong prompt is fixed here in a phase commit.
- Every prompt stands alone, in this form (the prompt audit of 2026-10-06): the why and a Done-when (the phase's Exit) first; what to read, not AGENTS.md, which loads with the session; the stops and the unattended defaults in one sentence after the start gate; the change; the tests; a reviewer-agent pass before the commit where a launch or the mod carries the risk (0.01.03 to 0.01.07); the commit, pushed with CI green; a Report that backs each claim with output from the session. docs/plans/m1.md holds each phase's exact change and the decisions D17-D26; docs/roadmap.md the findings, D1-D12, D27 and D28. 0.01.02 predates this form and ran as written.
